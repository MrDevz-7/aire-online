# AirE_Online — Frontend

Interfaz web del proyecto: dashboard público de solo lectura + panel de
administración con login.

## Requisitos

- Node.js 20 o superior
- El gateway corriendo en `http://localhost:4000` (ver `../gateway/README.md`
  y `../docker-compose.yml`)

## Instalación

```powershell
cd frontend
npm install
copy .env.example .env.local
